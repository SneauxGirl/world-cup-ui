# Country flags

Landscape flag SVGs come from **[flag-icons](https://github.com/lipis/flag-icons)** (MIT License).

- Package: `flag-icons` on npm
- Format: 4:3 (`fi fi-xx` classes; do not use `fis` unless you need 1:1 squares)
- Mapping: `lib/countryFlags.ts` (FIFA-style codes → ISO / `gb-eng`, `gb-sct`, etc.)

No attribution required for MIT, but crediting the project in release notes is appreciated.
